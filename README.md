# 🎵 Sistema Musical

## 📌 Sobre o projeto

O Sistema Musical é um projeto desenvolvido durante as aulas de LIMA, com o objetivo de criar um site para organizar e apresentar informações sobre artistas e músicas.

O desenvolvimento foi realizado no Visual Studio Code, utilizando HTML e CSS para construir a parte visual do sistema (front-end). Durante as aulas, fomos criando e melhorando as páginas, aprendendo a utilizar diferentes recursos para deixar o site organizado, bonito e fácil de usar.

## 🎨 Tecnologias utilizadas

- **HTML:** utilizado para estruturar as páginas, formulários, tabelas, campos e botões.
- **CSS:** utilizado para personalizar o visual do site, trabalhar com cores, espaçamentos, alinhamentos e deixar as páginas responsivas.
- **Visual Studio Code:** editor utilizado para escrever e organizar os códigos.

## 💻 Funcionalidades desenvolvidas

Durante o projeto, foram desenvolvidas algumas telas principais:

- **Tela de Login:** página inicial para acessar o sistema, com formulário centralizado.
- **Menu Principal:** apresenta as opções do sistema em cards organizados em uma grade.
- **Biblioteca Musical:** exibe as músicas cadastradas em uma tabela, com campos de busca e filtros por artista e gênero.
- **Cadastro de Artistas:** permite preencher as informações dos artistas e selecionar uma foto.
- **Cadastro de Músicas:** possui campos para informar o nome da música, escolher o artista, adicionar o gênero, inserir o link do YouTube e escrever a letra.

## 📱 Organização e design

Para organizar o visual do sistema, utilizamos recursos do CSS como Flexbox e Grid, além de variáveis de cores para manter um padrão entre as páginas.

Também adicionamos diferentes estilos aos botões, formulários e tabelas. Na parte final do projeto, trabalhamos com responsividade, permitindo que as páginas se adaptem melhor a telas menores, como celulares.

## 📚 Aprendizados

Com esse projeto, consegui praticar e desenvolver meus conhecimentos em HTML e CSS, principalmente na criação de formulários, tabelas, menus e organização de layouts.

Também aprendi a importância de reutilizar estilos em diferentes páginas, organizar melhor os arquivos e desenvolver um projeto por etapas, aproveitando o que foi aprendido em cada aula.

## 🚀 Conclusão

O desenvolvimento do Sistema Musical foi uma experiência importante para colocar em prática os conhecimentos adquiridos durante as aulas. Conseguimos construir a parte visual de um sistema que poderia ser utilizado de verdade, deixando preparada a estrutura para, futuramente, receber o back-end com PHP e banco de dados.

Foi uma oportunidade de aprender mais sobre desenvolvimento web e entender melhor como funciona a criação de um projeto desde o início.
